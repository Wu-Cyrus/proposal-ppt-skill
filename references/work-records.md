# 逐页方案、素材与决定记录

由AI根据材料整理可读表格，不要求用户先填表。只保留本次制作与续作需要的信息，短任务可合并为一份工作记录。

## 逐页方案

用稳定编号S001等，并另列显示页码；插入新页无需重编号。

| 字段 | 要求 |
|---|---|
| 页面编号、页码、章节 | 支持局部修改 |
| 标题、要回答的问题 | 一页聚焦明确主题 |
| 正文要点、核心结论 | 有依据，区分建议和假设 |
| 演讲主线与过渡 | 本页要讲清的逻辑、对应图文、承接与引出；备注中另写完整可照读正文 |
| 内容来源 | 文件名、小节或论文页码/图号 |
| 参考版式 | 模板文件与页次，固定元素 |
| 小板块组织方式 | 选用方式、适用理由、材料依据；内容参考与视觉主模板分开记录 |
| 素材编号、图位与状态 | 已有、待补、待确认、已替换 |
| 待确认事项 | 问题、影响、用户决定及范围 |

研究方案页另记三条编号任务的具体文本和各自论文/报告依据；将三条结构列为锁定项。每个含科研图的页面记录正常整页观看时的可读性结论，以及放大、换布局、取子图或拆页等处理结果。

## 分类与图位映射

- 研究现状记录“大类、交付页码、同页代表工作列表”。
- 背景记录“模板页码、模板有效图位数、交付页码、已填图位、空白图位、缺图用途”。分别核对每页下限和全章总数，装饰与流程节点不计数。

## 素材清单

图片用I001等，流程图用D001等，无须按实际页码命名。记录：

- 编号、文件名或来源页次、所属页面与位置。
- 获准范围：用户上传、指定论文提取、明确允许的其他来源；记录实际指令，不虚构批准状态。
- 用途、支持论点、必要来源信息。
- 原比例、分辨率或原生对象类型、裁剪限制。
- 状态：已有可用、待补、需核实、需替换、已放入。
- 流程图源PPT、页次或组对象，导入后是否可编辑。
- 记录页面实际显示的出处文字（作者/单位、刊会、年份、短题名或工作名称）及是否为重点论文；完整文献来源保存在本清单与备注，不能替代页面出处。图片旁不显示参考序号，已补齐的正式图注不显示I/D素材编号。

## 缺项示例

仅展示格式，不代表任何课题的真实事实。

| 编号 | 位置 | 需要补充 | 用途与要求 | 建议 |
|---|---|---|---|---|
| I003 | S004右侧 | 复杂地形图片 | 展示报告中的环境特征，附来源，不替代性能证据 | 横图、保留原图 |
| D002 | S012下方 | 足地接触建模流程图 | 按已确认报告表达输入、处理、输出和验证；不确定模块列问题 | 可编辑PPTX |

页面仅写简短待补提示，完整需求放备注后部“素材与待补说明（不朗读）”及清单。备注前部保留可直接照读的演讲稿，其后为“内容来源（不朗读）”；图位映射、来源文件名和制作记录不得挤占或混入演讲正文。不要用可见说明塞满制作步骤。

## 决定与续作

- 记录报告/主模板版本、结构、页数和时长、素材边界、目标软件与当前稿件。
- 区分用户确认、材料事实、AI建议和尚待确认。助手提过建议不等于用户同意。
- 记录改了哪些页及原因，沿用有效决定，不重问已经解决的问题。
- 重大歧义只暂停相关决定，继续其他部分。缺图本身不需要重新询问是否允许占位初稿。
- 初次风格探索可建议三页样稿，不让后续调用固定重走该阶段；用户直接授权整套制作时遵从。
