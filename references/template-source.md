# 内置模板来源与使用

- `assets/proposal-template.pptx`：在原《开题答辩规范化模板_含填写说明.pptx》的20页之后，追加8张可编辑正文备选页，共28页。原20页的页面对象、备注、母版和版式保持原样，封面第1页、目录第3页不变。文件整体已更新，不再是原文件的逐字节副本。
- `references/reference-format.md`：在原《开题报告PPT格式规范.md》基础上按用户要求持续修订，原规范来自两份学长稿的归纳，不是学校正式发布的规范。
- 来源文件库标识：模板 `libfile_8349ee5b336c8191b8d91c604f4cdb78`，规范 `libfile_244c38ca34dc8191b482c4c33107f9b6`。仅在用户要求刷新来源时用于定位；日常使用内置副本，不依赖旧对话。

## 使用规则

1. 没有新指定主模板时，说明将用此默认参考，继续可确定工作，不为常规套版额外索要授权。
2. 先读每页备注并查看渲染。第2和第20页是原使用说明，正式稿删除；原其余18页是结构范例。第21—28页为正文备选页，按下表选用，不整套附在正式稿后面；正式稿总页数由任务确定。原20页保留原示例页码，备选页标“备选01—08”，生成正式稿后统一按实际页序重算页码。
3. 替换填写提示和示例事实，保留框线、栏目与固定视觉对象。模板流程图示意/素材占位不代表用户已提供研究流程图。
4. 默认4∶3，25.4×19.05 cm，白底，蓝色通栏白字章节标题，黑体正文，红色关键字，浅粉色小标题底条，蓝色总结框，虚线分隔，右下角当前页/总页数。
5. 参考字号：封面题目36 pt，报告类别32 pt，章节标题36 pt，目录及方案小标题28 pt，主要正文24 pt，图注16—18 pt。以对应参考页实际属性为准，保留局部差异。
6. 默认本科七章：研究目的和意义；国内外研究现状及分析；研究目标及研究内容；研究方案；进度安排与预期成果；研究基础及经费预算；可能遇到的困难及解决措施。不同学位或学校要求不得硬套本科结构。
7. 内置规范的流程图样式描述只用于理解用户图或提出需求，不代表授权AI自行绘图；本次用户限制优先。
8. 新指定模板取代本次默认，不覆盖技能内置源文件；用户要求更新技能时才修改这些资源。
9. 原格式规范与PPT保留为历史参考。用户现行硬要求优先：图中文字不可读时调整正文区域版式和图位大小；图片旁不显示文献参考序号；每个研究方案内容页必须保留（1）（2）（3）三条任务。原规范中“常见三项，也有四项”不再作为改变三条结构的依据。三条占位词需用指定论文与报告中的实际任务替换，依次交代输入/条件/模型、核心方法/实现、输出/验证，不能删掉条目。

10. 背景图位下限：模板第4、5、6页分别有3、6、1个有效图片图位，共10个。第6页右侧的三个流程节点不计图片，第7页是研究意义文字页。复用时缺图保留空白图框，不削减图位或背景页面。研究现状按本次报告的大类一类一页集中呈现，不按模板现状页数硬凑，也不按单个案例扩页。

## 可直接选用的正文备选页

正文备选页承载 [内容组织选项](content-organization.md) 中的17种写法，一种页面可支持多种论述，不需要为每种写法创建一页。选用最合适的原生页面再替换内容，不能只读取文字规则而忽略已提供的可编辑版式。

| 实际页次 / 编号 | 页面形式 | 用途及替换位置 |
|---|---|---|
| 21 / L01 | 任务、能力、问题三栏，3个空白图位 | 任务收束到瓶颈或能力互补，对应原第4页，维持3图位 |
| 22 / L02 | 上排环境/特性，下排对应问题，6个空白图位 | 从对象特性解释困难，对应原第5页；原第6页1图位、第7页意义页继续保留 |
| 23 / L03 | 同类代表工作三栏，每项含出处、图位、方法及结果 | 同维度比较或同类研究阶段/分支；按真实工作数调整同页容量，不强行删至三项 |
| 24 / L04 | 分析维度、已有进展、具体不足、待解决问题表 | 对应综合现状分析，按材料选取维度 |
| 25 / L05 | 目标文字与研究内容、输入依赖、输出、验证依据表 | 说明研究任务接口，对应研究目标与内容；已有总体路线图时也可用原第12页 |
| 26 / L06 | 左侧三条完整任务，右侧大图位 | 对应各研究方案页，兼容建模辨识、数据处理、设计与验证等组织方式 |
| 27 / L07 | 方法/设置图与结果图对照，下附评价表 | 研究基础内的已完成工作，必须具有本人真实结果，不新增目录章节 |
| 28 / L08 | 困难、影响、针对措施逐项对应表 | 对应困难及措施；项目数按实际内容调整 |

- 新页中的正文、出处和表格均为可编辑对象，空白图框留作用户素材图位，未将研究流程图画成示例事实。
- 新页备注先放可填写的学术演讲稿，再放内容组织来源及模板选用说明。制作实际PPT时必须按课题重写并核实，不保留填空稿作为成品讲稿。
- 原模板中与后续硬规则不同的占位写法仍按最新技能纠正：背景缺图框内留空、页面明确文章出处、方案保留三条任务。不得把“原页保留”误解为允许绕过这些规则。
