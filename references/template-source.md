# 内置模板使用与页次映射

`assets/proposal-template.pptx` 是28页通用开题答辩模板。各类正文备选页与所属章节相邻排列，保留原有封面、目录和固定视觉样式。页面、备注及配套文档已去除个人参考稿的姓名、学号、具体课题、个人文件名和私人文件标识，只保留通用占位内容与组织方法。本模板不是学校正式发布的规范，也不包含可直接当作当前研究事实的案例。

## 使用规则

1. 没有新指定主模板时，使用内置模板继续已授权工作；用户指定新模板时，以其为视觉依据。
2. 先看页面渲染并读备注。第1页封面、第3页目录、第28页结束页；第2、27页为使用说明，正式稿删除。正文按下表选用，不因模板有28页而整套搬入正式稿。完成选页后重算全部页码。
3. 替换填写提示和示例文字，保留框线、栏目及固定视觉对象。占位图框和方法节点仅说明布局，不代表已提供科研图片或技术路线。材料不足时按技能规则留空并说明。
4. 默认4∶3，25.4×19.05 cm，白底、蓝色通栏白字章节标题、黑体正文、红色关键字、浅粉色小标题底条、蓝色总结框、虚线分隔及右下角页码。保留原封面、目录与结束页样式。
5. 参考字号：封面题目36 pt，报告类别32 pt，章节标题36 pt，目录及方案小标题28 pt，主要正文24 pt，图注16—18 pt。以对应页面实际属性为准，保留局部差异；公式按MathType硬性要求。
6. 默认七章：研究目的和意义；国内外研究现状及分析；研究目标及研究内容；研究方案；进度安排与预期成果；研究基础及经费预算；可能遇到的困难及解决措施。不同学位或学校要求以本次材料为准。
7. 模板中的框图样式只用于理解用户已有图或提出素材需求，不构成自行绘制研究流程图的授权。每个研究方案页必须保留（1）（2）（3）三条可见任务，依次交代输入/条件/模型、核心方法/实现、输出/验证。
8. 所有研究现状大类仍各占一页，同类代表工作完整集中呈现；本章的多种版式供选择，不按模板页数凑研究大类或将每个案例拆页。
9. 背景图位下限：第4、5页二选一，均3图位；第6、7页二选一，均6图位；第8页1图位，第9页为意义文字页。对应下限为3、6、1，共10个有效图位。第8页右侧方法节点不计图片；缺图框内留空，不能删图位或删必要背景页，也不把替代版式重复计入下限。
10. 新指定模板只用于当前任务；只有用户要求更新技能时才修改内置资源。模板维护或公开发布时检查正文、备注、元数据和配套引用中的个人信息，并保持以下页次映射一致。此规则不删除实际研究稿应有的学术文献出处。

## 按板块选择页面

| 板块 | 实际页次 | 版式与选用关系 |
|---|---|---|
| 封面与目录 | 1、3 | 填写信息，保留视觉样式 |
| 任务背景 | 4、5 | 3图位；第4页为任务图文，第5页（L01）为任务、能力、问题三栏，二选一 |
| 环境与困难 | 6、7 | 6图位；第6页为环境与局限，第7页（L02）为环境/特性与对应问题，二选一 |
| 研究切入点与意义 | 8、9 | 第8页1图位及方法位置说明，第9页凝练研究意义 |
| 同类研究现状 | 10—12 | 第10页三组图文，第11页四组图文，第12页（L03）三栏共同维度比较；按实际大类选择或复制，每类只占一页 |
| 对比与综合分析 | 13—15 | 第13页方法对比表，第14页文字分析，第15页（L04）进展、不足与问题表；按材料选用 |
| 目标与研究内容 | 16、17 | 第16页任务关系图，第17页（L05）输入依赖、输出与验证表 |
| 研究方案 | 18—21 | 第18—20页为三个方案的结构范例；第21页（L06）为三条任务配右侧大图，可替换相应方案页 |
| 进度与成果 | 22 | 阶段任务与产出表 |
| 基础与经费 | 23、24 | 第23页真实条件及经费，第24页（L07）方法/设置、结果图与证据表，只在有本人真实结果时选用 |
| 困难与措施 | 25、26 | 第25页问题与措施分组，第26页（L08）困难、影响与措施表，按实际内容选用 |
| 使用与交付检查 | 2、27 | 模板说明，正式稿删除 |
| 结束页 | 28 | 位于最后，保留原样式 |

8张正文备选页（L01—L08）支持 [17种内容组织方法](content-organization.md)，并非一种写法对应一页。文字、表格及占位图框均为原生可编辑对象。选用后填写实际内容，删除未选页面，不将备选编号带入正式稿。

备注中的填空式演讲稿用于展示逻辑组织，不能当作课题事实或成品讲稿。制作实际PPT时，按最终页面重写可照读的学术讲稿，随后记录完整内容来源与缺项。模板资源匿名化不影响正式稿对真实论文作者、刊会、年份及图号的准确标注。
