# 开题报告 PPT 格式规范

本规范依据用户于 2026 年 9 月 23 日提供的两份 PPT 归纳，用于后续严格沿用同类开题答辩形式。它是用户指定的参考样式，不代表学校统一发布的格式要求。

参考文件：
- 《1160800125丰文浩-毕业设计开题答辩_模板.pptx》：18 页，本科毕业设计开题答辩。Library ID：libfile_01c7edc688a88191aeaf91b94e9d3aec。
- 《开题报告.pptx》：29 页，硕士学位论文开题报告。Library ID：libfile_572cd3706e6c8191a2e078ea3cb5a577。

## 当前用户规则（优先于历史样例）

- 研究现状每个大类一页，同类各项工作合并比较，不按单篇论文或机器人分页。
- 背景有效图位数至少达到标准PPT的逐页数量与全章总数，缺图留空。内置模板原20页中的背景图片版式对应第4页3个、第5页6个、第6页1个，共10个有效图位；第7页为意义文字页。第6页的三个方法框不计作图片。新增第21、22页可分别替换第4、5页，仍保留3、6图位；备选页不额外计入标准背景图位下限。若用户指定新的标准PPT，应重新实测，不直接套用10个。
- 缺图框内保持空白，框外图注写用途和待补状态。保留相关背景页，不用单幅大图或文字替代多个图位。

## 1. 使用原则

以原 PPT 为视觉基准，保留原有页面比例、封面校徽、蓝色标题栏、标题位置、基础边框、分隔线、基本栏目文字和页码。以后制作时优先复制最接近的原版页面，再替换内容。除非用户另有要求，不重新设计成另一套视觉风格，也不把模板清空成只剩背景。

本科开题默认采用 18 页参考稿的章节结构；研究背景、文献综述和研究方案的具体表达可以参考 29 页稿。总页数根据汇报时长和内容确定，18 页与 29 页是参考稿页数，不是固定要求。

## 2. 固定视觉规范

| 项目 | 执行规范 |
|---|---|
| 页面 | 横向 4∶3，25.4 cm × 19.05 cm |
| 背景 | 白色 |
| 内容页页眉 | 顶端蓝色通栏，白色章节标题，左对齐；沿用原模板的位置与尺寸 |
| 配色 | 蓝色为主，黑色正文，红色强调词；保留浅粉色小标题底条、蓝色细框和虚线分隔 |
| 字体 | 中文以黑体为主；本科参考稿的图注较多使用微软雅黑，少量信息使用宋体；按被复制页面保持一致 |
| 封面 | 左上校徽；上方报告类别；中部课题题目；下方排列姓名、学号或学科、导师、日期等信息 |
| 页码 | 右下角“当前页/总页数”，包括封面和结束页；增删页后同步更新 |
| 结束页 | 白底，居中大字“恳请各位老师提出宝贵意见”，沿用原稿分行方式 |

主要字号来自原文件的文本及版式属性，实际套版时应以具体参考页为准：

| 文本层级 | 参考字号 |
|---|---|
| 封面课题题目 | 36 pt |
| 封面报告类别 | 32 pt |
| 内容页页眉章节标题 | 常用 36 pt |
| 目录 | 28 pt |
| 研究方案编号及小节标题 | 常用 28 pt |
| 正文、普通小标题、总结文字 | 常用 24 pt |
| 图注、机构及年份标注 | 常用 16–18 pt |
| 结束页致谢文字 | 66 pt |

原稿包含个别局部字号差异，不应把所有文字强制改成同一字号。信息过多时优先精简或拆页，维持主要正文的可读性。

## 3. 本科版章节结构及参考页次

| 部分 | 本科参考页次 | 内容组织要求 |
|---|---|---|
| 封面 | 1 | 报告类别、题目、姓名、学号、导师、日期 |
| 汇报内容 | 2 | 七个章节，使用“一、二、三……”编号 |
| 一、研究目的和意义 | 3–6 | 任务背景、实际困难、拟采用思路或能力需求，最后归纳研究意义 |
| 二、国内外研究现状及分析 | 7–10 | 按技术方向分组展示代表工作，最后单列现状分析页 |
| 三、研究目标及研究内容 | 11 | 凝练研究任务，配总体关系图 |
| 四、研究方案 | 12–14 | 按 4.1、4.2、4.3 分项展开，文字任务与技术路线图对应 |
| 五、进度安排与预期成果 | 15 | 时间区间和各阶段工作、成果对应，优先用表格 |
| 六、研究基础及经费预算 | 16 | 上下两部分说明研究基础和经费条件 |
| 七、可能遇到的困难及解决措施 | 17 | 上部问题、下部措施，逐项对应 |
| 结束页 | 18 | 请求老师指导 |

硕士参考稿的结构差异：第一部分增加课题来源；第三部分合并“主要研究内容及研究方案”；第四部分单列“预期达到的目标”；第五部分增加已完成工作；第六部分区分已具备和仍需的条件、经费。

## 4. 各类页面的常用表达方式

本节提供基础写法；需要更多选择时使用 [小板块内容组织选项](content-organization.md)，并从内置模板第21—28页选择相应的可编辑正文备选页。可选择不同论述、比较和证据组织方式，但封面、目录、章节顺序与第2节固定视觉规范保持不变。内容参考稿不作为更换主模板的依据。

### 背景与意义页

- 使用任务图片、环境照片、实际失败案例、系统框架图或对比表建立研究动机。
- 常用“上部或中部图示＋底部蓝色细框总结”的版式，也可采用中部总结、上下图示。
- 总结语明确说明图示支持的结论，关键问题和能力需求用红字强调。
- 整个部分由任务需求逐步收束到具体研究问题，再归纳研究意义。
- 参考：本科第 3–6 页，硕士第 3–8 页。

### 国内外研究现状页

- 按研究对象或方法类别组织，不按论文阅读顺序堆叠。
- 顶部保留章节标题栏，下方设置本页研究方向小标题，常配浅粉色底条。
- 中部用论文原图、实验图、框架图或结果图展示代表工作；蓝色虚线分隔不同工作或类别。
- 图下注明作者/研究单位、期刊或会议名称、年份，并用文章短题名或工作名称对应具体论文；这是必填信息，不能沿用历史本科稿中仅标方法和年份的省略写法。重点论文突出刊会名称，完整书目信息放备注。
- 后续制作统一采用“工作名称/短题名＋作者/单位＋刊会＋年份＋方法＋主要结果”的信息组织方式，可分行排布，保持同类工作同页且出处可读。主要结果必须有材料依据。
- 讲稿配套解释“哪个单位针对什么问题、用了什么方法、得到什么结论、还存在什么限制”；不把全部讲稿塞进幻灯片。
- 最后单列“研究现状分析/综述”，将现有不足与自己的研究内容对应。
- 参考：本科第 7–10 页，硕士第 9–14 页。

### 研究目标与内容总览页

- 简要列出主要研究任务，配一张总体关系图。
- 任务名称与后续方案页标题一致，体现任务之间的依赖或支撑关系。
- 按实际课题确定任务数量。两份参考稿的方案部分均展开三项任务，这属于参考组织方式。
- 参考：本科第 11 页，硕士第 15 页。

### 研究方案页

- 页眉保留本章名称，正文以“4.1/4.2/4.3”或所在章节对应编号标明研究任务。
- 上方或左上列出若干子任务，采用“（1）（2）（3）……”编号；参考稿常见三项，也有四项。
- 下方或右侧放技术路线、模型示意、计算流程或系统框架，占据主要版面。
- 流程图以矩形框、连线/箭头、蓝色或浅蓝色填充表达关系，保持原模板的科研图示风格。
- 文字任务与图中模块逐项对应，交代输入、方法、输出和验证方式。
- 需要数学表达时，围绕研究方法放置必要公式、变量定义和模型示意，不为增加数学感堆叠无关公式。
- 参考：本科第 12–14 页，硕士第 16–18 页。

### 已完成工作页（有真实工作时使用）

- 使用真实的数据样例、软件界面、实验结果、公式推导或模型对比证明研究基础。
- 一页聚焦一项已完成工作，明确目前完成程度，不把计划内容表述为既有成果。
- 参考：硕士第 20–25 页。

### 计划、条件与困难页

- 进度表按照“时间区间＋具体任务及预期产出”组织；本科参考稿使用浅蓝色表格。
- 条件页区分已有基础与仍需条件，经费按实际情况填写。
- 困难页使用上下两块结构，分别列问题与解决措施；措施要能对应具体问题。

## 5. 写作与信息组织要求

1. 每页聚焦一个明确主题；图示、正文和总结共同支持该主题。
2. 正文使用正式、简洁的学术表达，以必要说明、分点任务和结论为主。
3. 红色仅用于关键概念、问题、结果或研究不足，保留正常黑色正文层次。
4. 研究背景解释为什么需要研究；现状分析明确缺口；研究内容和方案回应缺口；进度及基础证明可行性。
5. 图片须与论点直接相关，保持原比例；文献图应能看清关键部分。
6. 具体学校、年份、方法、数据、文献、项目来源和已完成成果必须来自材料或核实后的来源。
7. 沿用版式时修正原稿的错别字、重复字及时间错误，不把内容错误当作格式规范保留。

## 6. 后续制作验收清单

### 公式学术排版（MathType 强制）

- 所有公式统一使用可编辑的 MathType 公式对象，包括行内、独立、表格和流程图中的公式；Office 原生公式和普通文字均不能替代。纯截图或仅含图形的 SVG/EMF 即使显示清晰，也不满足 MathType 要求。论文原图中含有需要展示或讲解的公式时，核对原式并用 MathType 单独呈现，不能只靠图片中的公式通过验收；不得改造原图而改变科研证据。
- 公式采用统一的 MathType 数学样式，拉丁字母优先 Times New Roman，希腊字母和数学符号使用相应数学字体。标量变量用斜体，向量和矩阵统一用粗斜体；函数名、运算符名称、单位及说明性上下标用正体，变量和索引上下标用斜体。全文保持符号含义、大小写和量纲一致。
- 主公式字号通常以24—30 pt为起点，根据模板和实际显示尺寸调整；分式、上下标和积分限在整页放映时也应可读。长公式在数学关系明确的位置分行，对齐等号或关系符，不横向压扁、不靠缩小到不可读来塞入图位。
- 独立公式居中或与正文逻辑对齐，仅对需要后续引用的关键公式编号，编号右对齐并与正文引用一致；不强制给每个公式编号。首次出现的关键符号就近解释物理含义，必要时标单位。
- 按“一句话说明目的—核心公式—关键符号与物理意义—图示或结论”组织内容，不为增加数学感堆叠推导，不用公式取代研究方案的三条编号任务。备注解释公式的用途及与当页图文的关系，引用公式的来源保持可追溯。
- 导出后逐式检查真实公式数据、嵌入对象关系、符号及显示效果；渲染正确不等于 MathType 可编辑。在具备 MathType 的环境中抽查打开并编辑对象，未实际执行时如实说明，不能把静态显示验证说成编辑验证。工具不支持或存在未转换公式时列明页次与公式，保留可恢复的源表达式，标为待补稿，不能判定为合格成品。

### 通用检查

- [ ] 4∶3 比例、白底、蓝色通栏标题及右下角页码正确。
- [ ] 原校徽、基本框线、小标题底条、分隔线和栏目文字按参考页保留。
- [ ] 字体、字号、颜色、标题位置与原版相符。
- [ ] 章节结构与所选本科/硕士参考一致，变动有当前任务依据。
- [ ] 背景页图文共同说明问题，并有清楚结论。
- [ ] 现状页按方向分类，具有来源标注及单独的现状分析页。
- [ ] 研究内容与研究方案逐项对应，方案包含清楚的技术路线。
- [ ] 任务时间、预期成果、已有条件及困难措施前后一致。
- [ ] 页码、日期、姓名、导师、题目等信息全部更新。
- [ ] 无溢出、遮挡、乱码、错误裁切和过小文字。

## 7. 可直接复用的制作指令

请严格按照《开题报告PPT格式规范》及所附两份参考 PPT 制作。默认采用本科参考稿的七章结构，保持 4∶3 白底、原校徽、蓝色通栏白字章节标题、黑体正文、红色关键词、浅粉色小标题底条、蓝色总结框、虚线分隔和右下角页码。保留原模板的基本框架和栏目文字，优先复制合适的原页替换内容。研究现状按照技术方向分类，以科研图片配研究单位、年份、方法和主要结论，并单列不足分析；研究方案采用任务分点配技术路线图。内容、章节页数和研究事实以本次材料为准。
